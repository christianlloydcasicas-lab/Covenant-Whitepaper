# 🏛️ COVENANT ($COV)

A decentralized, programmable relational lifecycle engine designed to establish economic stability for modern marriages, protect child trust assets, and mathematically mitigate adversarial divorce costs. Built on secure 2-of-2 state-gated multi-signature infrastructure.

---

## 🗺️ Protocol Architecture Overview

Covenant functions as an automated family sovereign fund split into three sequential lifecycles:

1. **The Foundation Tier (Marriage):** Couples cryptographically bind their wallets into a strict 2-of-2 state layout, pooling joint stablecoin assets (USDC) into low-risk automated lending registries while unlocking time-weighted **Tenure Multipliers** that increase yield percentages for every consecutive year they remain together.
2. **The Generational Tier (Birth):** Leverages Zero-Knowledge Proofs (ZKPs) via decentralized validation layers to verify birth registry events without leaking sensitive civil data on-chain. Birth events scale the household's yield tiers and initialize an immutable **Generational Trust Sub-Wallet** for the child, time-locked tightly for exactly 18 years.
3. **The Stabilizer Tier (Divorce Prevention):** Combats impulsive separations by enforcing an un-bypassable **90-day isolation escrow freeze** upon any dissolution trigger. If the conflict resolution/reconciliation route is rejected, the engine executes a mathematically absolute 50/50 token partition instantly, completely bypassing predatory courtroom fees.

## 🚀 Dev Setup & Local Sandbox Testing

To compile and simulate contract states locally inside the free Remix IDE workspace:

1. Clone this repository or copy the code from `CovenantVault.sol`.
2. Open [Remix IDE](https://ethereum.org) and create a new contract file.
3. Set the Solidity Compiler target constraint to version `0.8.20` or higher and hit compile.
4. Navigate to the transaction deployer tab, select the default **Remix VM** sandbox, input a mock stablecoin address parameter, and deploy to simulate lifecycle metrics for absolute zero cost.
